# About this project

This repository features a hardware design and code for an ESP32S3 Wroom. With the provided ressources it is possible, to turn any ordinary, non-programmable school calculator into a powerful and programmable device, that connects to the internet via Wifi.
One possible usecase for such a device is the communication with LLM's like ChatGPT, which is implemented in the code.
There are two versions of hardware available. The second, newer version allows for an installation in any calculator with small changes (to the UI-Board and some 3D-prints). The first version is designed specifically to be compatible with the Casio FX87 or FX991.

This is an independent modification, I am not affiliated with Casio Computer Co.,Ltd. or Casio Europe GmbH in any way.
